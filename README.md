# Darkroom Finish

**把想要的感觉说出来，让 AI 帮你修照片。**

中文 · [English](README.en.md)

Darkroom Finish 是一个带摄影知识库的 AI 修图 Skill，可以配合 Codex 使用。你选一张 RAW，告诉它想要什么感觉；它先看照片，再从知识库里找合适的参考和方法，调用你电脑上的 Photoshop / Camera Raw 做出初版。

看过结果，你可以继续说：“颜色再克制一点。”“暗部的气氛保留下来。”它会结合反馈调整，并留下每一版的配方和结果。

## 为什么做这个

喜欢拍照，不代表也喜欢花几个小时做后期。有时候，你知道自己想要安静一点、有生活气息一点，却不知道该从哪个滑块开始。

Darkroom Finish 想帮你跨过的，就是从“我想要这种感觉”到“这张照片具体怎么修”的距离：找到方向、查阅方法、完成软件操作，再一起看结果。

你不必先把想法翻译成一串参数。照片最后是不是你想要的，仍然由你决定。

## 用起来是什么样

完成安装和环境检查后，可以直接对助手说：

> 用 darkroom-finish 帮我修这张 RAW。想要安静一点，颜色克制一些，但保留现场的光线和气氛。先看看照片适合怎么处理，再给我一个初版。

也可以暂时没有明确的风格：

> 这张照片我很喜欢，但不知道怎么修。先帮我看看值得保留的地方，再推荐一个适合它的方向，说明理由。

先说感觉，看初版，再聊细节。你可以提出具体修改，也可以说这一版不如原来的。

## 摄影知识库，是它修图的依据

这个 Skill 的核心不只是让 AI 操作 Photoshop，而是让它在动手前有资料可查：一张参考作品的光线、颜色和空间关系为什么成立？哪些做法适合眼前这张照片，哪些不适合？

当前开源包自带：

- **195 份摄影师研究档案**：从简短线索到较详细的作品与方法笔记。
- **423 份教程整理笔记**：记录后期思路、候选方法和需要进一步核实的内容。
- **10 类场景、40 个参考方向**：帮助它从照片本身出发寻找参考，而不是只凭“日系”“电影感”选一个滤镜。

这些资料随 Skill 一起下载，不需要连接作者的私人知识库。保存的是研究文字、方法说明和来源链接，不是打包好的摄影作品、视频课程或摄影师预设。

它也不是训练出了一个“会模仿 195 位摄影师”的模型。资料的深度和可靠程度不同，其中 51 份档案仍缺少可回查的来源；研究线索不能当作已经验证的修图能力。[查看知识库详情](https://github.com/pessiilee-eng/darkroom-finish/blob/main/docs/KNOWLEDGE-SCOPE.md)

## 一句话背后，它做了什么

**照片 + 你的想法 → 看图 → 查知识 → 制定调整 → 本机修图 → 看结果、听反馈**

1. **先看这张照片。** 理解主体、光线、颜色和你想保留的东西，不急着套风格。
2. **再找适合的参考。** 阅读相关作品研究和方法，判断哪些值得借鉴。参考作品打不开时，要说明只能依据文字做尝试。
3. **把想法变成调整。** 将方向落实为当前工具支持的明暗、白平衡、颜色、曲线或局部操作，并记录为什么这样做。
4. **让本机软件执行。** Photoshop / Camera Raw 处理 RAW 的工作副本，原片保持不动。
5. **回到画面判断。** 看整体、前后对比和必要的局部细节，再结合你的反馈修正。默认最多尝试三版；做不到的地方要说明，不无限重试。

AI 负责看图和规划，知识库提供参考，本机工具负责执行；你保留最后的判断。

## 开始之前

目前适合愿意尝试 AI 修图工作流、手头已有 Adobe 软件的 Mac 用户。你需要：

- macOS，以及已安装、可用的 Photoshop 和 Camera Raw。
- Codex，或能读取 Skill、运行本机命令并在获准后看图的 AI 助手。其他助手的兼容性尚未逐一验证。
- Python 3.11 或以上。

### 安装与第一次使用

1. 从 [Releases](https://github.com/pessiilee-eng/darkroom-finish/releases/latest) 下载公开安装包，解压得到整个 `darkroom-finish` 文件夹。不要只复制 `SKILL.md`，知识库和工具也在里面。
2. 在一个新的测试项目里，将整个文件夹放到 `.agents/skills/darkroom-finish/`。如果已有同名 Skill，先不要覆盖。助手没有自动识别时，让它读取这个文件夹里的 `SKILL.md`。
3. 请助手按 [新电脑验证指南](https://github.com/pessiilee-eng/darkroom-finish/blob/main/docs/TESTING.md) 先用生成的测试图检查环境，再处理你指定的一张 RAW。第一次运行时，macOS 可能会询问是否允许控制 Photoshop。

照片的工作副本和修图结果应放在独立的私人工作区，不要放进 Skill 安装目录，也不要提交到 GitHub。

## 关于照片与隐私

原始 RAW 和全尺寸导出留在本机，程序本身没有自动上传功能。但如果使用云端 AI，**让 AI 看图也意味着把预览发给对应服务**；这一步需要你的许可，使用的是去除元数据、缩小后的预览，不是 RAW。

每次修图会保留图片结果和配方，便于比较、继续调整和检查。不要把私人工作区附在公开 issue 中；本地导出也可能带有照片元数据，公开分享前需要另行检查。

## 遇到问题，怎么反馈？

欢迎在 [GitHub Issues](https://github.com/pessiilee-eng/darkroom-finish/issues) 反馈，中文、英文都可以。先看看是否已有相同问题；没有的话，登录 GitHub 后点击 [New issue](https://github.com/pessiilee-eng/darkroom-finish/issues/new)。

不只是报错才值得反馈。安装卡住、修图结果不符合你的想法、知识资料有误，或者某一步特别费劲，都可以说。标题可以用“安装问题”“效果反馈”“知识纠错”或“改进建议”开头。

尽量告诉我们：

- 你原本想完成什么，以及给助手的要求（去掉私人信息）。
- 实际发生了什么；如果是效果问题，具体说哪里不对，比如颜色、明暗或没有保留你在意的部分。
- 哪几步之后出现问题，能否再次遇到。
- Skill 版本、macOS / Photoshop / Camera Raw 版本，以及所用 AI 助手。安装问题还可补充 Python 版本。
- 如有报错，只贴检查并脱敏后的相关几行，不要上传整个日志或工作区。

**Issues 是公开的，请先用文字描述，不要上传私人照片、RAW、完整对话、个人路径或密钥。** 如果必须用照片才能说明，先讨论是否能用不含隐私、且你有权公开的测试素材复现；不要为了反馈而公开自己的相册。

反馈会帮助定位问题出在安装、照片理解、知识选择、软件执行还是结果检查。单张照片的偏好不应直接变成对所有照片的固定规则；涉及工作流的修改，需要结合复现和回归验证。

## 它现在还不是万能修图师

当前版本面向**单张 RAW 的调整与风格尝试**，普通 JPEG 输入不在这一版范围内。它不提供生成式填充、换天空、人物塑形、自动磨皮或整库批处理，也不是手机修图 App。

知识库中有些方法还没有接入工具，不能看到一篇教程就认为它已经会执行。公开版已通过本机 Adobe 合成测试，但第二台实体 Mac 和新照片的实际效果仍待验证；不保证每张照片一次修好，也不保证不同电脑得到完全相同的结果。[查看测试与已知限制](https://github.com/pessiilee-eng/darkroom-finish/blob/main/docs/RELEASE-STATUS.md)
