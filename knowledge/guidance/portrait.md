## 1. S3：先写一个能被看见的结果

延续主流程的题材、背景、光线、风格、强度、用途六维输入，再补三项：**人物与谁／什么发生关系；成片观看时脸有多大；用户希望修饰到什么程度**。能从授权图与已有要求判断的自行判断；未知写明，不能把文字 brief 当成已经看过图。

| 场景 | 优先表达与修饰深度 | 必须防止的误修 |
|---|---|---|
| 旅行／环境人像 | 人物状态与地点共同成立；先裁框和画面主次，再做正常观看可见的局部问题 | 裁掉有意义的手势、窗框、环境；脸亮得脱离现场光 |
| 日常／亲密写真 | 普通表情、关系距离、柔和或有方向的现场光；肤色健康但保留本人特征 | 把“日本感”直接写成低饱和、偏青或增白；为亲密感一律裁特写 |
| 街头人物／纪实 | 动作、颜色呼应、现场关系；脸可以处于阴影中 | 自动提亮所有面孔、磨皮或删除有叙事作用的路人 |
| 棚拍／商业近景 | 按 brief 检查妆容、服饰和皮肤细节，可用更细的局部修饰 | 将商业美容的深度复制到旅行小脸；未经要求改变五官、身形、年龄特征 |

原光的软硬、方向与光源颜色决定能成立的明暗和肤色关系。硬光并非缺陷，深肤色不以变浅为目标；明亮也不等于没有阴影。环境中的暖光、绿反射要判断是否妨碍表达，不能全部校白。依据 D01–D06；分类与应用顺序是本项目综合。

意图写进**本图现有计划**，不用另造表单：

> 先看到【人物的动作／神情】，再读到【环境关系】；保留【原光向和结构阴影】。肤色保留【原有深浅与合理局部差异】，减轻【有依据的问题】。环境主色／服装辅助色／保护色为【各自角色】。裁剪保留【关系】，清除【干扰】。在【手机全图／近景／打印】尺度验收。

如用户已认可颜色、只要求皮肤或构图修改，绑定那个版本的母版与哈希；不得从另一旧版本开始，也不顺手重做已认可颜色。

## 2. 先拆“脸脏”，再选工具

对同一版本依次看彩色全图、正常展示大小、足够分辨率的原尺寸局部，再看中性明暗辅助图。辅助图可能改变皮肤各颜色的明暗关系，必须回到彩色确认。没有相应细节权限或图像分辨率时，报告无法核实的部分。

| 诊断 | 需要的证据 | 最小干预方向 | 保护与退出 |
|---|---|---|---|
| 整体曝光／白平衡问题 | 人、衣服和环境共同失衡；基线也存在 | 先校基础影调／白平衡，再评局部 | 保留关键肤质高光、原光方向及现场灯色 |
| 大尺度明暗不匀 | 颜色基本相容，某亮暗过渡妨碍正常观看；与合理体积阴影区分 | 局部明暗均衡；是否另做塑形单独决定 | 颧骨、鼻翼、下颌体积不能一起变平 |
| 局部色偏 | 彩色可见红／黄／绿块，未必在中性明暗图同样突出 | 局部色相／饱和度或颜色分量修正 | 不把红斑直接加曝光；保留腮红、唇色和合理反光 |
| 单点临时瑕疵 | 可定位、确实需要处理，周围存在可用纹理 | 小范围可撤回修复 | 不复制出重复纹理，不将痣／雀斑默认认作瑕疵 |
| 细纹理／噪声问题 | 在对应输出尺度仍干扰；与正常毛孔、细毛、失焦区分 | 降噪或有限纹理处理，按成因选择 | 平滑不能恢复失焦；毛孔减少本身不是成功指标 |
| 前一轮副作用 | 同位置在基线较自然，新增块边、灰斑、发际线粗细断层等 | 先撤回出问题的那一步，再改范围／方法 | 不能用更多平滑遮盖上一轮边界；不叠改 JPEG 当母版 |

允许多种问题并存。记录观察、原因假设及信心；不要仅凭“暗”“红”或算法名字断定原因。优先处理对成片最显眼的一个问题，分别开关颜色、明暗与纹理步骤，避免不知道收益来自哪里。

若母版已多次修皮肤，先比对同一 RAW、同坐标的早期版本。早期真实纹理可以恢复，但早期版本不必然没有原生暗斑。恢复前核对 RAW 身份、尺寸、方向、ICC 与结构对齐；颜色或构图不同的旧图不能整张替换当前基线。亮度修正后仍显灰时，先重新检查色度；正常邻居被一起抬亮形成亮环时，应从该步之前分支并限制作用亮度范围，不能继续提高整个区域。

## 3. S4–S5：专业手法怎么转为执行计划

下列左侧是学习到的专业操作思路。**右侧能力检查先通过，才能实际执行**；不能因知道 Photoshop 菜单就绕过 card_pipeline。依据 R1–R7 与既有 P01–P06。

| 目标与专业手法 | 具体步骤及可观察的停止点 | 原本地能力映射（本公开包未接入）与限制 |
|---|---|---|
| 明暗均衡：曲线 D&B | 提亮／压暗曲线分别配黑蒙版，笔触对应斑块尺度；每区开关，再退回整图。周围一起变亮说明范围过大，局部反而凸起就减回；宏观塑形与微观均衡分开 | 可编辑曲线层／笔触传输尚未准入。`local.harmonic_tone_balance` 只作候选低频均衡，`local.skin_control_field` 只作手工局部控制；二者不能命名为已复现专业 D&B |
| 局部偏红：颜色范围与空间范围共同约束 | 用 Hue/Saturation 取样并限制 Reds 范围，再通过黑蒙版只恢复目标区；分别检查唇、腮红、衣服。若向黄灰滑移就回退 | 当前 PS 图层路径和 ACR Color Range 未准入；Lab 控制场或 harmonic 色度候选只能按其真实语义单独验证，不等价于该教程 |
| 脸／颈／手颜色关系 | 取同一人、相近光照和明暗面的合理区域参照，再有限调整；阴影颈部不能机械匹配受光脸部 | 不设置统一“标准肤色” RGB、CMYK 或肤色线目标；本地控制场需逐图指定目标与范围 |
| 临时小瑕疵／细杂发 | 独立像素层、关闭污染取样的辅助层、小笔触；Spot Healing 自动采样，Healing／Clone 可指定采样；失败撤回该笔，再缩小范围 | 当前卡执行器没有已准入的修复／克隆笔触路径；不能改称平滑以代替 |
| 频率分离 | 按本图细节确定尺度，先验证空操作重组不改变输入，再有限分层修饰；单独检查高光、眼神光、唇反光、发际线与体积 | 当前未准入。低频含形体，非纯颜色；教程半径和 8/16-bit 设置不能直接照搬。本地双边滤波不是分频 |
| 恢复同源真实皮肤 | 从未经问题步骤处理的同一帧恢复同坐标像素，或仅替换细节残差；恢复后重看颗粒、明暗与边界，不凭空增加纹理 | 候选 `local.same_source_restore` 显式冻结两份母版与 RAW 身份，支持有限多边形和保护区。定义（本地材料未随包分发）。只替换残差时扣除当前残差，避免重复叠加；没有可用同源细节时不能承诺恢复 |
| 只减轻暗斑，避免亮邻居同步抬高 | 空间笔触与原输入亮度范围共同限制；在低频亮度上判定作用强度，将修正施加于原亮度。检查斑块是否消失、过渡是否凸起，再独立检查色偏 | 候选 `local.tonal_brush` 是有冻结亮度门控的 Lab L 控制场，定义（本地材料未随包分发）。不模糊输出、不等价于 PS 原生 D&B/Blend If；具体亮度门限随该图诊断，不套用“标准皮肤亮度” |
| 有限纹理平滑 | 仅在明暗／颜色原因已排查后试用；列保护特征与累计处理次数，检查皮肤与未修区的过渡 | 原本地实现候选 `local.skin_texture_smoothing`（本公开包未接入），是 RGB 双边处理；没有识别毛孔与瑕疵的语义能力，不代表自然肤质已验证 |

不搬运作者的固定 Flow、半径、色温或 CMYK 比例。半径以**实际执行母版像素**为单位；1600 预览上的定位需按原方向、裁框和尺寸映射。新工具先非用户夹具验证、登记准入，再进入被授权的照片试验。

## 4. 局部皮肤操作的执行约束

- 每步写明基线母版、问题、区域、采样参照、操作维度、强度、保护对象、预期变化、失败信号。保存可回放配方与实际输出；名称“磨皮”不足以说明做了什么。

- 面部蒙版要区分皮肤、眉睫、眼白、唇、鼻孔、发际线、首饰及高光。保护对象不只要不被写入，也要检查是否通过采样污染内侧。

- 先逐操作核对保护能力：既有多边形平滑没有孔洞；9月9日的低频取样候选支持共享椭圆排除，但不识别面部语义、不支持可变笔压。覆盖不了保护区时，缩小到有明确收益的小区域；确实需要更细能力时停该步骤并记录缺口，不以一个大区域包住整张脸。

- 记录上游已用的局部处理和重叠区域。两次重叠、在已平滑母版上再做一次，都会改变累计作用；每次合法的强度上限不代表累计自然。不能把重复一遍叫新技术路线。

- 范围外像素不变只是保护检查之一；另查边界环的纹理与色彩连续性、低反差细毛、原有高光和面部体积。方差／高频能量下降也可能是正常纹理被删。

- 使用已认可母版做后处理时，仅用管线的已验证母版入口并核对依赖、来源和基线哈希；没有重新经 ACR 的步骤要明确写成母版派生。Adobe 操作证据是继承，不伪称重新核实。

- 预算继承主 skill 与 runtime-limits。同图相同算法改坐标、叠遍数或改 run 名不重置预算。用户明确重新授权持续迭代时，记录续做范围与实际新增假设，保留旧失败；不能将再授权解释为原路线已通过或扩大照片／外发范围。

## 5. S8：人像怎样算比上一版好

检查顺序是**正常成片 → 原尺寸关键细节 → 放回整组**，同时与同基线比较。没有看到真实输出，不填“已通过”。

| 层次 | 判断问题 | 否决信号 |
|---|---|---|
| 表达 | 先看到约定的人物状态与关系了吗？现场光仍成立吗？ | 只有脸亮了／平了，叙事反而弱；人物像贴上去 |
| 肤色和体积 | 脸、颈、手在各自光照下协调，颜色有细微变化吗？ | 漂白、橙黄统一、灰绿斑、两颊如同色块；鼻颧结构消失 |
| 肌理和边缘 | 毛孔、细毛、眉睫、唇缘、眼神光自然吗？处理区衔接吗？ | 蜡感、重复纹理、模糊条带、发际线断层、锐化光圈 |
| 输出和系列 | 手机尺寸能看见收益吗？本组同一个人的表达协调吗？ | 仅超大放大才更“平”；换到手机显暗／灰；同组每张肤色跳变 |

皮肤变化可以比环境风格变化细微，不为“看得出修过”而加重。环境电影感和自然皮肤可以并存；肤色应处于现场光中，不能机械剥离成中性贴片。数值检查负责找剪切、范围泄漏、边界与重放差异；不能给“漂亮”“真实”发证。

## 6. 少量样片下如何学与验

1. **先用公开案例学习一件事。** 区分看过结果、读过步骤、实际复演；能合法取得同原片才称作者案例复演。只给 JPEG 的案例不证明 RAW 能力。素材不随 skill 分享。

2. **再测工具的失败边界。** 合成或许可明确的非用户夹具验证：不操作时不变、目标响应、范围、保护特征、边界、单次与累计处理、色度／低频副作用。只给数值结果不能声称皮肤自然。

3. **最后检验真实迁移。** 在用户已授权且仍允许试验的集合里，以不同拍摄日／场景分组；同处连拍不拆成开发与验证。已反馈的照片只作回归，未授权范围不自行搜索补齐。

覆盖优先级：旅行中等脸＋逆光／侧光；亲密近景＋可辨纹理；林荫绿反射／窗边混合光；夜景高感；街头小脸／剪影这一“不应美容”反例。再交叉肤色深浅、年龄纹理、单／多人和输出用途。覆盖维度不代表必须一次做全笛卡尔积，也不等于已掌握这些类型。

每个开发实验只增加一个关键方法，固定颜色／裁框等无关变量；知识增益实验则按主协议让两臂各自定意图，不能将新方案喂给旧流程。冻结推荐后匿名比较，允许无差别、各有取舍、都不满意；记录首次可交付、缺陷、返工、最终接受及实际评审者。教程作者成片可作参照，不能把模型自评分或像素接近度当真人高手对照。

缺少新照片不妨碍补知识和工具探针；它会限制画质与泛化结论。用户无需另招修图师、给每篇教程评分。遵循正式质量门和正常交付验收，不因本模块写成就增加审美分数。
