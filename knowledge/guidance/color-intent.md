## 把氛围写成画面关系

在原有单图意图里明确：

- 现场光色、天气和真实光向是什么；要保留什么。

- 主色、辅助色、点睛色分别在画面哪里，怎样服务所选故事或感觉；据其材质、距离、天气、受光或人物联系的作用，决定保留、弱化或改变。保护色只来自当前表达的需要。

- 黑位密度、中间调分离、高光收束与空间远近如何服务情绪。

- 预计观者在普通观看尺度能指出的变化，以及最容易受损的肤色、材质、雾、灯色或细节。

“自然”“高级”“电影感”“通透”单独出现不算可执行方向。“阴天城市”也不自动等于全局变冷；需要说明深绿前景、青灰远处、暖屋面各自如何被组织。这里的例子说明具体程度，不是给所有照片套同一配色。

色彩统一或保留多样性都应服务所选表达。森林绿、水蓝、晨雾暖光只是可能有作用的例子；若目标依靠它们说明天气与距离，统一黄灰会损伤表达，若另有成立的色形意图，也可有选择地简化。颜色更多或更少都不自动更高级。一次接受某张暖色照片，不意味着其他场景都适用全局暖罩；一次否定黄偏也不意味着所有暖光都应去掉。

纠偏先定位被否定的是无处不在的色罩、受光关系还是整体方向，再重新实现该图所选感受。As Shot、零分离色调或中性色只是一种起点，不能作为去黄后的默认终点。目标依靠暖阳时，应让其来向、落点和受光材质在画面中成立，同时保留未受同样照明区域的区别；不能只恢复某个色温数字，也不能把温暖均匀铺到全部暗部。

明暗密度与颜色鲜艳程度分别决定。目标是浓郁植被时，深绿暗部、受光叶片和其间反差可能共同承担生命力；单独提亮绿色可能把体积摊平，单独压暗也可能堵住枝叶。依据所选感觉安排暗部深度、中间调间距、亮部面积与色彩浓度，并在预览中检查其共同效果。清淡、浓郁、明快或幽暗各有成立条件，不从场景名称自动选档，也不写通用滑块幅度。

纠偏需同时检查受影响的区域、影调范围和面积：某处更黑不等于全图更暗，某处暖阳更强不等于环境一并变黄。计划中列出哪些关系应增强、哪些仍需保持，并检查曝光、曲线、HSL 和局部操作叠加后的总效果。真实历史配方可以用提白与压黑同时打开影调两端，也可以抬阴影保住环境；这些是作用关系的例子，不是新通用预设。

## 按作用选工具，避免只做亮度校正

| 要解决的问题 | 可考虑的已分类控制 | 保护与判断 |
|---|---|---|
| 基准色偏与光源关系 | WhiteBalance / Temperature / Tint | As Shot 可以正确，也可能保留无意色偏；自定义白平衡并非完成指标。不得为了中和而抹平夕光、灯光或环境色。 |
| 单一色系抢眼或不同色系混成一团 | HSL 的 Hue / Saturation / Luminance 分别判断 | 降饱和只改变鲜艳程度；还要判断是否需要色相和明度分离。同色控制会波及天空、衣物、皮肤等其他区域。 |
| 反差组织、黑位密度与高光收束 | RGB 点曲线、准入的参数式影调控制 | 保住材质与空气感；直线可有理由保留，非线性不自动更好。曲线还可能影响饱和度，调整后回查。 |
| 阴影与亮部缺少有意图的色彩关系 | 当前准入的分离色调控制及平衡 | 从原光色情境选择冷暖或同色层次，不把所有阴影染青、所有高光染橙；不能污染肤色和应保留的灯色。 |
| 视觉重量需要局部调整 | 先辨别是否真是局部问题，再核对 registry 与运行限制 | 全局 HSL 不等于空间蒙版；不以全局改色假装局部精修，也不启用未验证／未授权方法。 |

以上是候选方法，不是每张必须打开的开关清单。工具数量、参数幅度、彩色直方图变化都不能充当氛围分数。低饱和、泛黄或暗角不能自动代表电影感；是否使用看它能否强化所选表达、代价是否值得。低饱和、黑白、清淡画面仍可成立，不必为证明修过而增色或增加局部操作。

S5 对每张只记录有意义的采用／保留理由，把预定变化映射到可执行参数。调用旧中性卡时，检查其默认值有没有原封不动地覆盖表达设计；已有字段没有使用属于创作选择，不能声称工具不支持。

Adobe 官方当前文档的 Curve / Color Mixer / Color Grading 说明支持这些控制的基本分工，[来源 S13](../sources/2026-09-10-composition-crop-and-color.md)。当前执行能力逐项以 registry 与方法规格（本地材料未随包分发） 为准；新版三路 Color Grading 不能直接当作当前旧式 Split Toning 字段的等价实现。文档读取、写入、原生读回、探针、回放分别保留证据状态。

## 验收先看表达，再查解释

测试预览应先可见地兑现选定的感受、光向、明暗密度与观看顺序，再继续完整成片导出和交付；看到改善方向仍不等于力度已经到位。若准入局部操作必须先生成全尺寸 TIFF 与重放才能提供预览，这些是本机测试中间件，不能因已出文件便视为成片通过。预览未达到视觉目标时，在既有预算与授权内回到意图或方法，不把判断留给完整导出后的用户。

第一遍隐藏参数和作者解释，按最终观看尺寸看整体故事或感觉是否成立。第二遍用同裁框中性图比较，指出服务意图的可见变化，再核验该意图下的保护色及作用；不能只找一处成功而忽略必要关系的失败。若目标是受光人物与空间的联系，就看它是否连贯，白纸／桌面更亮不能证明这一点；其他表达可以有不同的光色组织。没有变化可以如实记录；所选表达未出现，或它依赖的颜色关系受损时，不能凭无噪点、无光晕保留为完成候选。

评审已指出的核心缺失必须改变选优结果，不能降格为“仍可加强”“有改善”的交付附注。用于诊断的未达标试验可以明确展示，但不能挂为已还原或主推荐；原作仍优时保持原作为当前优选。用户通过只绑定其实际确认的版本，之后的专项修订不能顺手改动它。

这里判的是表达是否成立，不是用了哪些滑块。弱饱和晨雾可能只需整理明暗层次，就能让远近与清淡情绪成立；只要实际画面支持，不必额外染色或加曲线。相反，打开全部调色工具却没有明确关系，也不能通过。

然后核对“意图→计划→卡→实际输出记录→真实可见效果”。只有执行记录一致仍不足以证明审美成立；也不能因看起来更浓就忽略肤色、天空、暗部与空间的损失。

色彩和构图分开比较，再放回整组。组内共享表达，跨场景保留不同光线的性格。用户已认可的颜色在裁剪专项中冻结；用户否决氛围时，回到方向与方法，不仅微调曝光，也不把旧失败评语继续当认可。用户指定原成片为本轮标杆后，最终比较须明确新图在哪些故事、空间和颜色关系上更好／相当／更差；不能只对上一张 AI 失败版证明有变化。没有可见优势就如实保留原成片为当前优选，不为交付新版本而强行选新图。

遇到明确的整组方向否决，先完成复盘与规则对齐；对齐后先用少量已授权代表图校准实际效果，再考虑展开。不得先处理整批再让用户承担方向筛查，也不得用新 run/ID 重置已用纠偏预算。

## 方法证据与停止边界

- **问题与预期**：防止基础光影校正被当作完整表达；希望配色、密度和空间关系能在真实成片中被指出。

- **原理与顺序**：现场观察→可见意图→按作用选法→逐图实施→同裁框视觉比较→全构图／整组检查。无须复制教程数值。

- **副作用**：统一滤镜、肤色污染、彩色暗部、去雾破坏天气、曲线压死材质、为追求变化而过饱和。

- **失败与停止**：效果只停在基础校正且不符合 brief，或出现保护对象损伤时，记录方向／执行失败并在剩余预算内纠偏；预算尽时保留失败并按主流程换路线，不追加版本掩盖。
