## 方法拆解 (L1)

Shibata 的公开访谈集中在**拍摄期操作与选片纪律**（大画幅+Zone System 底座、
排除天空/尺度的取景规则）；暗房放大级参数（相纸/药液/分区加减光数值）未见
公开量化，该层走 L2。

- **技术底座：Zone System + 大画幅（作者原话）**：〔直接引文略，参见公开来源〕——从画家转行
  摄影时直接以 Adams 分区曝光法自学起步；影调控制是其黑白工艺的方法论根基
  [cited](https://www.marcfeustel.com/eyecurious/interview-with-toshio-shibata)。
  大画幅选择源于研究 Edward Weston / Group f.64 的印相质量：〔直接引文略，参见公开来源〕（自学冲洗与曝光；此前有丝网版画经验）
  [cited](https://robhutcharch.com/interview-toshio-shibata)。

- **器材与产量纪律（作者原话）**：〔直接引文略，参见公开来源〕——8×10 座机；成片率
  自我设定约 1%，剔除"时间指向性过强"的画面。选片即方法：风格一致性靠
  淘汰而非拍摄参数
  [cited](https://www.marcfeustel.com/eyecurious/interview-with-toshio-shibata)。

- **取景规则一：排除天空（作者原话）**：〔直接引文略，参见公开来源〕——刻意不收天空/地平线，切断画面与"真实
  世界"的坐标联系 [cited](https://robhutcharch.com/interview-toshio-shibata)。

- **取景规则二：消灭尺度（作者原话）**：〔直接引文略，参见公开来源〕——不给参照物，使水坝/护坡在画面里失去大小感，趋向抽象图形
  [cited](https://robhutcharch.com/interview-toshio-shibata)。

- **现场节奏（作者原话）**：〔直接引文略，参见公开来源〕——找到位置后数分钟
  内架机完成拍摄；大画幅但不做长时间等光 
  [cited](https://robhutcharch.com/interview-toshio-shibata)。

- **胶片实证**：Polaroid Type 55（4×5 正负片）用于一批风景创作——Nazraeli
  One Picture Book #20《Type 55》即〔直接引文略，参见公开来源〕
  [cited](https://www.nazraeli.com/opb/toshio-shibata-one-picture-book-20-type-55)。

- **黑白→彩色的目标函数切换（作者原话）**：黑白拍满 20 年后转彩色；
  〔直接引文略，参见公开来源〕——黑白=形状+影调（Zone System
  语汇），彩色=氛围（大气透视/湿度/植被色）；两期应配不同技术卡目标
  [cited](https://www.marcfeustel.com/eyecurious/interview-with-toshio-shibata)。

- **暗房纪律（作者原话，未给参数）**：〔直接引文略，参见公开来源〕——承认暗房是重工序但未公开配方
  [cited](https://global.canon/en/newcosmos/interview/toshio-shibata/index.html)。

- **数字迁移蒸馏**（供技术卡引用，非作者原话）[common-practice]：
  ①构图门禁：无天空、无地平线、无人物/车辆等尺度参照，结构充满画面；
  ②黑白期目标=Zone System 式全域影调：黑场留密度（L2 p1≈8-30 不死黑）、
  高光不剪切（p99≤247）、中间调因题材大幅摆动（p50 59-169），不追统一
  中灰；③彩色期目标=低饱和"氛围"：sat_mean 0.12-0.31、青绿/土黄主导，
  灰调水泥与植被绿的并置是色彩骨架。

## 历史外观统计（未复核；禁止参数化）

> 下列是历史笔记中的描述记录。样本、测量文件与核验过程未随包分发，本包未复核这些数字；不得把它们当作摄影师操作、通用目标阈值或可执行参数。外观统计不能唯一反推出编辑步骤。

- 解读：aggregate 黑场 p1=14.9（黑保密度）、中位 p50=92.5、高光 p90=187 /
  白点 p99=224（不剪切）、对比 spread=158——大画幅"全域有层次"的影调签名；
  sat_mean=0.09 是黑白（0.03-0.11）与彩色（0.12-0.31）两期的混合中值，
  彩色期也止于低-中饱和，青绿/土黄色相主导（水泥灰 vs 植被绿的并置），
  无高饱和色偏；黑白期中位跨度极大（p50 59-169）——影调由被摄结构决定
  而非固定灰卡，符合其 Zone System 逐场景配置的工作方式。

- 补充：日系安静美学在地誌/建筑摄影中的体现；与工业遗产/社会议题相连。
