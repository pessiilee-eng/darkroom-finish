## 1. 肤色保护与还原

### 规则1.1: HSL 橙色通道处理（亚洲肤色基准）

**应用场景**: 所有亚洲肤色人像  
**关键参数范围**:

- **橙色 Hue**: ±5 到 ±15（轻微调整，避免过度偏移）

- **橙色 Saturation**: -10 到 -30（降低过饱和感，保留自然肌理）

- **橙色 Luminance**: +5 到 +15（提亮肤色，创造透射感）

**最佳实践**:

- 优先调Luminance而非Saturation，保留肤色细节

- Saturation负值幅度：欠曝肤色 -15~-20，正常肤色 -10~-15

- Luminance正值幅度：室内/阴天 +15，户外亮光 +5~+10

**来源**: `[common-practice, uncited]` - Lightroom HSL调整的摄影教学通用实践

---

### 规则1.2: HSL 红色通道补充处理

**应用场景**: 唇部、腮红、高光区域过饱和控制  
**参数范围**:

- **红色 Saturation**: -5 到 -20（细致控制，避免失血色）

- **红色 Luminance**: 0 到 +10（必要时微调，通常保持中性）

**约束条件**:

- 仅当橙色处理后红色通道仍显过饱时使用

- 负Saturation幅度不超过绿色/蓝色，保持肤色层次

**来源**: `[common-practice, uncited]` - HSL分通道处理的标准实践

---

### 规则1.3: 肤色与白平衡关系

**色温 (Temperature) 容差范围**:

- **晴天户外**: 5500K 基准，±300K 内可接受（保留光影）

- **阴天/树荫**: 6500-7000K，±200K（降低偏蓝感）

- **钨丝灯**: 3200-3500K，±150K（见规则3）

- **荧光灯**: 4000-4200K，±250K（混光补正）

**Tint (绿/洋红) 平衡**:

- **基准**: 0 到 -5（轻微负值补冷，常见做法）

- **室内暖光**: -10 到 -20（抵消过暖洋红）

- **过曝肤色**: +5 到 +15（恢复血色）

**调整顺序**:

1. 先用Temp大幅修正色温偏差

2. 用Tint微调，优先修正肤色而非中性灰

3. 再行HSL细调

**来源**: 

- `[cited]` Wikipedia Portrait Photography 对布光与光温的讨论基础
  - https://en.wikipedia.org/wiki/Portrait_photography

- `[common-practice, uncited]` Camera Raw 色温校正的标准工作流

## 2. 逆光人像

### 规则2.1: 脸部欠曝全局补救

**参数优先级** (应用顺序):

1. **Exposure**: +0.3 到 +1.0 EV
   - 轻欠曝 (+0.3~+0.5)
   - 中度欠曝 (+0.5~+0.8)
   - 严重欠曝 (+0.8~+1.0)

2. **Shadows**: +20 到 +60
   - 单独拉Shadows避免高光溅白
   - 优先于全局Exposure调整

3. **Blacks**: -10 到 0（保留对比，避免灰蒙蒙）

**禁忌**:

- 不超过 +1.5 EV Exposure（噪点/伪色溅出）

- Highlights 不触发（保护天空/背光）

**来源**: `[common-practice, uncited]` - Lightroom RAW处理的标准曝光补救流程

---

### 规则2.2: 逆光光晕/Flare 控制

**Dehaze 使用**:

- **清晰化 (Clarity)**：-10 到 -20（柔和光晕，不过度磨皮）

- **Dehaze**: -15 到 -40
  - 轻微雾霭: -15~-25
  - 浓雾/强逆光: -25~-40

- **Vibrance**: -5 到 +10（按需微调，保留肤色）

**替代方案**: 

- 若Dehaze过度损失细节，改用Clarity负值+轻微降饱和

**来源**: `[common-practice, uncited]` - 逆光环境中光晕处理的通用参数策略

---

### 规则2.3: 逆光剪影判断

**保留剪影条件**:

- 拍摄意图是轮廓/戏剧感（如日落逆光肖像）

- 环境光强度 > 被摄体5倍以上

**做法**:

- Exposure 仅小幅调整 (+0.2 以内)

- Shadows 保持 0 或轻微正值 (+5~+10)

- Highlights 压低 -20 以下，保护背景细节

- `[cited]` Wikipedia Portrait Photography - 三点布光理论中的亮度分配原则
  - https://en.wikipedia.org/wiki/Portrait_photography

## 3. 室内钨丝灯人像

### 规则3.1: 暖光下肤色校正 vs 氛围保留

**策略分支**:

#### 方案A: 最大保留氛围（推荐旅拍）

- **Temperature**: +200~+500K（不完全校正，保留暖调）

- **Tint**: -5 到 -15（轻微绿移，平衡洋红过度）

- **Saturation**: -5（全局轻降，避免饱和灼烧）

- **HSL 橙色 Luminance**: +8~+12（补偿暖光昏暗）

**适用**: 秋景、室内酒吧、黄金时段、文艺氛围优先

#### 方案B: 完全色温校正（广告/商业）

- **Temperature**: -300~-500K（接近日光 5500K）

- **Tint**: +10~+20（补偿蓝移洋红不足）

- **结合方案A的HSL处理**

**适用**: 肤色准确性优先于氛围（如护肤品广告）

**来源**: `[common-practice, uncited]` - 色温校正中的美学权衡策略（摄影教学通用）

### 规则3.2: 分离色调补偿

**高光分离色调**:

- **Hue**: 30~60°（偏黄）

- **Saturation**: 10~25（保留暖感）

**阴影分离色调**:

- **Hue**: 210~240°（偏蓝补冷）

- **Saturation**: 5~15（轻微，避免过冷）

**用途**: 抵消色温校正的过度感，保留电影感

**来源**: `[common-practice, uncited]` - 分离色调调色法的标准应用

## 4. 正午硬光人像

### 规则4.1: 高反差直射光处理

**参数层级**:

1. **Contrast**: +10 到 +30
   - 低光下 +20~+30（增强气势）
   - 晴天正午 +15~+25（避免过硬）

2. **Highlights**: -20 到 -50
   - 轻微溅白: -20~-30
   - 严重溅白: -30~-50
   - 禁止超过 -60（画面乌黑感）

3. **Shadows**: +10 到 +35
   - 轻调: +10~+20
   - 中度: +20~+35
   - 配合Blacks: -5~+5 保留对比

4. **Clarity**: 0 到 +15（增强纹理感，但面部不超 +10）

**来源**: `[cited]` Fstoppers 社区 - 〔直接引文略，参见公开来源〕 实战讨论

- https://www.fstoppers.com/

- 同时参考 `[common-practice, uncited]` 高对比处理的参数范围

### 规则4.2: 曲线微调

**推荐曲线形状**: S 曲线或梯形

- 阴影点: 上提 +5~+15（拉亮暗部）

- 中调点: 0（保留中调准确）

- 高光点: 下压 -10~-20（控制亮部溅白）

**目标**: 保留光影戏剧感同时恢复细节

**来源**: `[common-practice, uncited]` - 曲线调整的标准实践

## 5. 日系旅拍人像调色

### 规则5.1: 低饱和奶油色调基础

**全局处理**:

- **Saturation**: -15 到 -25（低饱和基调，不超 -30）

- **Vibrance**: 0 到 +15（保留肤色活力，补偿Saturation的平淡）

**曲线黑场上提（胶片感关键）**:

- **Blacks点**: 提升到 +15~+30
  - 轻度奶油: +15
  - 浓郁胶片: +25~+30

- 效果: 削弱对比，增强雾蒙感

**来源**: `[common-practice, uncited]` - 日系调色美学的参数实现（摄影社区通用）

---

### 规则5.2: 分离色调（日系必用）

**高光**:

- **Hue**: 40~60°（暖黄）

- **Saturation**: 15~30

- **目标**: 高光偏暖，增强日系温度感

**阴影**:

- **Hue**: 200~230°（淡蓝）

- **Saturation**: 10~20

- **目标**: 暗部偏冷，制造色彩对比

**参考摄影师风格**:

- 金浩森 (Kanazashi Koji)：高Vibrance + 高分离色调饱和度

- 滨田英明 (Hideaki Hamada)：低Saturation + 轻微分离色调

**来源**: `[common-practice, uncited]` - 日系摄影师调色风格分析（训练知识）

---

### 规则5.3: HSL 绿蓝处理（背景协调）

**绿色通道** (背景/植被):

- **Saturation**: -15 到 -30（绿色容易溅出，需降饱）

- **Luminance**: -5 到 +10（背景虚化，暗一点更出人）

**蓝色通道** (天空/远景):

- **Saturation**: -10 到 -20（蓝天不宜过鲜艳）

- **Luminance**: +5 到 +15（蓝天偏亮，营造高调感）

- **Hue**: -5 到 +5°（微调蓝色倾向，青蓝vs普鲁士蓝）

**组合目标**: 人物突出，背景协调，形成"人物中心-背景陪衬"的视觉层级

**来源**: `[common-practice, uncited]` - HSL背景处理的标准实践

## 6. 通用纪律：Clarity/Texture 与 Vibrance 用法

### 规则6.1: 面部 Clarity 禁忌

**绝对禁区**:

- **正值 Clarity > +15 于面部**: 增强细纹、毛孔、痤疮（反效果）

- **负值 Clarity < -20 于面部**: 过度磨皮，丧失质感（不符合项目章程）

**允许范围**:

- **Clarity +5 到 +10**: 轻微锐化，增强眼神、嘴唇边缘定义

- **Clarity -5 到 0**: 轻微柔和，仅用于对比重的背景光晕（如镜面反光）

**最佳实践**: 

- Clarity 仅用全局或肤色以外区域（眼睛、唇部微调）

- 面部细节完全依赖HSL Saturation/Luminance 和 Vibrance

**来源**: `[common-practice, uncited]` - 人像后期处理中的Clarity使用禁忌（行业通用）

### 规则6.2: Vibrance vs Saturation 区别

**Vibrance**:

- **性质**: 智能饱和度，优先提升已欠饱的色彩，保护肤色

- **面部安全**: 正值可用 (+5 到 +25)

- **用途**: 快速增强整体活力而不伤肤色

**Saturation**:

- **性质**: 全局饱和度，无差别增强所有色彩

- **肤色风险**: 正值 > +10 易导致肤色溅出、显假

- **用途**: 精确控制，需配合HSL精调

**推荐组合**:

- 日常人像: Saturation -5 到 -15 (降低平淡感) + Vibrance +8 到 +15 (恢复活力)

- 低饱和奶油: Saturation -20 到 -25 + Vibrance 0 到 +5 (保持沉静)

- 高对比硬光: Saturation 0 + Vibrance +10 到 +20 (强化戏剧感)

**来源**: `[common-practice, uncited]` - Lightroom调整工具的设计特性与实战应用
