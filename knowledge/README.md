# 可携带暗房知识

> 发布状态：`reference_proposed`。这是历史研究／方法候选，不是摄影师参数复原、已验证配方或新照片效果承诺。原始研究中的阅读、评分和执行声明没有随包携带验证证据，均不授予执行能力；使用前按当前工具和照片复核。
> 仅保留原创归纳和公开出处，不包含第三方图片、音视频、字幕全文、课程素材或预设；原作版权归各权利人，软件许可证不授予这些原作的权利。
> 历史笔记可能讨论合成、塑形或生成操作；这些仅是研究背景，不属于本 Skill 的非生成式执行范围。

从 [40个场景方向](style-targets/scene-v1/catalog.json) 筛选，读 [完整方向与工作流](style-targets/scene-v1/atlas.json)，再按 [文档索引](index.json) 查作者档案、研究来源和视频方法候选。

先核对原图现有的空间、光、颜色、人物／纹理及拍摄依赖；按用途比较方向、边界例、适用和不适用条件。对每条关系写出原图依据、保持或改变、预期可见变化、保护对象、失败信号和回退。缺少必要拍摄条件可以不匹配，不能生成不存在的关系。

catalog 保存作品定位、观察、核心关系和方法；atlas 保存每个方向的故事、空间与裁剪、光影、颜色、纹理／人物、完整条件工作流及17条方法来源。作品 URL 是原出处，图片没有捆绑或自动下载；失效或无法查看时明确记录未知，不声称已看图。

photographers 是历史作者研究；sources 是原始方法归纳；video-notes 是带时间定位和不确定性的音轨蒸馏候选，未附音轨、字幕或全部屏幕核查证据。它们补充判断，不自动升级为可执行操作。历史 [works-v1](style-targets/works-v1/catalog.json) 仅供比较，不继承任何私人校准。

详细判断方法见 [题材与意图](guidance/genre-and-intent.md)、[构图与裁剪](guidance/composition-and-crop.md)、[色彩表达](guidance/color-intent.md)、[人像](guidance/portrait.md)、[作品目标选择](guidance/work-target-library.md)。这些完整方法文档经过个人案例脱敏，保留条件、推理、保护与失败判断。

输入原件保留在维护者本地。公开包不包含个人照片、私有配方、评分、经历、工作台地址、照片路径或私人评审证据。历史外观统计与迁移假设保留其完整上下文，明确未随包复核、不得直接参数化；原始验证状态不继承。详细处置账留在维护者本地，公开 manifest 仅列数量、版本和发布文件哈希。

条目保留历史时间背景，来源链接和人物事实可能已变化，使用时按需要复核。所有关系与方法均为 reference_proposed；本机执行必须由当前版本的能力检查和当前照片的实际验证决定。
