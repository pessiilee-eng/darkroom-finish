## 向谁学习

作品标准的准入须同时满足：真实身份、有连贯的相应作品、可核验的专业认可，以及对当前场景的迁移价值。专业认可采用重要机构收藏/展览、经同行遴选的摄影机构成员、可信奖项，或持续专业出版与有日期的策展展览记录。普通图库签约、付费头衔、单次高互动量不能单独准入；名气也不替代看作品。

作品标准与教学方法分开审核：优秀作品能支持画面关系；作者公开讲解才支持其实际创作方法；Adobe原文只支持工具机理。未公开的RAW参数不猜造，本项目的实现步骤明确标为迁移假设。

## 每个方向必须回答

先说明希望观众看到的关系，再用实际作品确定空间、光影、颜色、纹理/人物的目标；写清原材料条件、邻近方向差别、什么情况下不适合，以及缺口触发的具体动作、可见增量、停止信号和回退。颜色可主动增强已有物色和光色的关系，也可保持；不能只有避免过量。人像必须区分脸手明暗、色偏、表面纹理和身份特征。裁剪保留什么由本图故事决定，画幅按常规比例或原结构选择。
