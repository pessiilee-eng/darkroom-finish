# 下阶段照片测试协议 V1

> 发布状态：`reference_proposed`。这是历史研究／方法候选，不是摄影师参数复原、已验证配方或新照片效果承诺。原始研究中的阅读、评分和执行声明没有随包携带验证证据，均不授予执行能力；使用前按当前工具和照片复核。
> 仅保留原创归纳和公开出处，不包含第三方图片、音视频、字幕全文、课程素材或预设；原作版权归各权利人，软件许可证不授予这些原作的权利。
> 历史笔记可能讨论合成、塑形或生成操作；这些仅是研究背景，不属于本 Skill 的非生成式执行范围。

本轮只建库。以下在下一轮选图/调参之前固定，实际样本、方向、源与候选哈希填写到各run。既有完整执行与审查仍按多方向作品参照试验（本地材料未随包分发），本页不替代原有照片授权或票据。

**样本与目的。** 在已授权剩余照片池中分场景每批5张，先按未覆盖的关系/失败分支分组，再在可选范围内随机；同次连拍不冒充独立场景。说明哪些是已看开发样本，哪些未参与本版目标或参数调整。先固定库版本、路由记录、每条核心关系的原图缺口、keep/change与成功/失败信号，完整记录被排除或不匹配照片。

**比较材料。** 同框中性、候选、必要同色未裁对照和原生ROI分别登记角色、尺寸、ICC和SHA。预览统一sRGB且通过真实ICC转换、去元数据及授权长边限制；不只贴ICC标签。原生ROI用于皮肤、边缘、噪声/纹理，不能用缩略图声称通过。不同裁框须保留全框以检查丢失的空间关系。使用同一显示环境，并说明手机/桌面实际看过的范围和任何不可核验的色彩校准限制。

**谁怎样判断。** 显影者不能给自己的候选独立通过。另一角色先看匿名成片记录自发观察，再看到所选作品和目标，再比较版本，最后才读参数。每阶段冻结观察再进入下一阶段；泄漏提前信息时该条降为诊断，不伪称严格盲评。用户的喜好与接受最终单列，不用内部评分代替。

**逐关系判据。** 每条给`pass / fail / uncertain / not_applicable`与图上位置证据。change只有预登记的可见关系达到才pass；“略有变化”“没变坏”“参数非零”均不等于完成。keep需要证明该关系仍成立。全景检查观看路径、原有空间连接、光色载体及主次；任何关键关系fail或uncertain不可进主推荐。不能在成片失败后重写主旨或删除难项再通过。

**人物与副作用。** 原生对照检查新脸手暗斑、异常色差、眼发细节损失、皮肤蜡感、局部发亮轮廓、重复纹理、锐化光圈、天空断阶及不合理蒙版边。能定位新增损伤为fail，无法看清为uncertain，不能用“有电影感”覆盖。实际操作与意图分开核对，必要时关单项局部比较。没有真实单变量对照时不作确定归因。

**报告与回写。** 同时报告目标达成、原生副作用、用户偏好和不匹配，保留全部候选及失败原因。配方、蒙版、工具、参考或库版本变化后，相关旧通过不跨版本沿用。吸收反馈的照片成为开发回归材料；下一轮验证另取未参与该次修订的场景组。不将一次成功、5张成功或建设完整度外推为全照片成功率。

**独立性与分歧。** 独立评审者必须是未制作该候选的另一人或另一独立代理；同一显影者切换角色仍是自检，不能标作独立通过。同线程代理若已知作者说明或此前反馈，登记信息暴露，受影响阶段仅作诊断；不得冒称严格盲评。作者与评审者或多名评审者发生实质分歧时记录双方图上证据，结论先置 uncertain，补原生复看或第三方评审；作者不能自行覆盖为 pass。

**汇总如何触发行动。** 按“方向 × 核心关系”汇总各独立样本的 pass/fail/uncertain，并记录处置。单张任一关键 fail 已阻止该候选进入主推荐；同一核心关系在至少两个独立样本中 fail，触发该方向包复审和修订，重新冻结相关库/配方哈希，再用未参与修订的新样本回归。uncertain 先补原生检查或更换不适配参照，解决前不进入主推荐。保留修订原因、旧新哈希和复验结果；既有“单张三轮不过则换技术路线、连续两周盲评均分无提升则停工上报”仍生效，不能借触发阈值无限调参。
