# 公开版的知识库边界

本版是可独立安装的单张 RAW 实验内核，不是摄影师资料库发行版。

| 内容 | 本公开包的处理 |
|---|---|
| 通用画面判断、表达与颜色、构图、人像检查原则 | 重新编写，保存在 references/visual-judgment.md |
| 原摄影师人物档案、作品目标包、教程研究笔记 | 未复制进本包，不是运行时依赖 |
| 第三方作品图片、图文册、网页快照、视频、字幕、预设 | 不分发，也不自动下载 |
| 原用户照片、逐图配方、偏好、授权与历史审查 | 不分发；每位使用者的新工作区也应保持私有 |
| Adobe 字段与操作能力 | 保留受控注册表与编译器；字段可写不等于照片效果已验证 |

原研究路线把场景、风格标签、具体作品关系、实现假设和验证状态分开。
公开版本保留“先判断画面，再选择操作，最后看真实结果”的工作方式，但没有接入
那套具体作品检索与已研究案例。仅安装此包不会自动获得它们。

需要某位摄影师的参考时，应由用户提供可访问来源或另行研究，并区分：
看到的作品关系、作者公开讲解的方法、当前照片的实现假设。不要猜造作者真实 RAW
参数，也不要把某个名字直接转换为预设。本版不承诺大师风格还原。

后续若发布可选知识包，应逐条检查来源、原创归纳、可分发范围、个人信息和依赖，
优先提供原创分析与出处链接。公开可浏览不代表获得图片或课程的再分发许可；
原私人试验结果也不能自动成为新使用者的质量保证。MIT 只覆盖本仓库实际发布的内容，
不授予任何第三方作品或 Adobe 软件的权利。
