# 知识是 Skill 的核心构成

本版不再是只有执行器的 Alpha。安装包自带可分发的详细研究与检索入口；不用连接作者电脑。
完整文件、实际数量和处置统计以 [知识清单](../knowledge/manifest.json) 为准。

| 层 | 保存形式 | 用途与边界 |
|---|---|---|
| 摄影师档案 | photographers/*.md | 保留详细研究和出处；历史 qualified/verified 等描述不等于新用户验证 |
| 专题来源与教程候选 | sources/*.md、video-notes/*.md | 原创归纳与候选方法；不是原视频、字幕、课程或可直接照搬的数值预设 |
| 主作品目标库 | style-targets/scene-v1/*.json | 题材/标签→方向→作品关系→适配→方法→停止/回退；主库 40 方向、33 位关联作者、233 个作品条目 |
| 历史目标库 | style-targets/works-v1/*.json | 保留研究沿革，不累加成不同作者总数，也不继承原试验通过 |
| 检索与版本 | index.json、manifest.json | 按内容检索、逐文件哈希；作品 ID 只在方向内唯一 |

原库顶层有 196 份人物档案，另有隔离档案；按文件计，不宣称 196 个去重自然人或全部方法已验证。
本版提供其中 195 份，经审查其中 51 份没有可回查的 HTTP(S) 来源链接，部分只是简短历史名册线索，
不能把档案数量当成详细或已核实的方法数量。无来源条目须补源后才能用于人物事实或作者方法归因。
现存文字经隐私清理后导出，不能安全分离或缺少分发依据的内容保留本地主库并记处置原因，
不会为了开源删除原件。公开包不复制私人照片卡、偏好、反馈、源路径、授权和历史图像审查。
第三方图像、网页快照、视频、逐字字幕、预设和课程素材不随包分发。公开链接不代表再分发许可。

## 如何真的影响修图

按 [知识调用流程](../references/knowledge-workflow.md) 从图像问题检索，读完整方向及相关资料，
检查拍摄前提和不适用条件，再为每个关系写目标、失败信号和方法，最后绑定实际参数/蒙版/几何。
所有运行副本在私人工作区；编译器和重放共同校验知识快照与计划。
执行后回到该关系表检查画面是否兑现，而非只检查滑块变化。

库中作品观察是过去研究留下的文字，不替代本次看图。能访问参考时实际查看；无法访问时
明确标记“文本假设试修”，保留知识解释，但不得声称视觉风格匹配或专业效果已验证。
当前所有方向均为研究候选，不能根据过去的私人单图接受、文件数量或结构校验升级质量状态。

## 与作者本地系统的关系

本地主库仍单独管理；发布是单向只读导出，不回写、不搬迁、不覆盖本地 Skill 或执行器。
新学习先在本地追加和核验，再由维护者审查可公开部分生成新版。
公开库是有版本的可分享投影，不是删减后的新主库。安装者升级时新建工作区，旧快照和配方保留。

模型未记录的隐性知识无法声称全部写入了文件。能追溯的新增理解应记录来源、推理、适用边界
与验证状态后再入库；不能把模型自信、历史摘要或 AI 生成文本当作来源事实。
